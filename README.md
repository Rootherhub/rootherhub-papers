## How this registry works

Each entry below is the public record of a completed paper. For papers not yet published in an external outlet, the full manuscript is **privately held** and available to editors on request; this registry publishes the title, abstract, authorship, completion date, and the **SHA-256 fingerprint** of the exact manuscript file. The fingerprint plus the git commit timestamp constitutes verifiable proof of authorship and priority for the complete text as of the registered date — without releasing the text itself.

When a paper is published externally, its full text is added here with a canonical link to the publishing outlet.

**Verification:** given the manuscript file, `sha256sum <file>` must reproduce the fingerprint recorded in the paper's registry entry at the commit in which it was registered.
